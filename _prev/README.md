# Previous Portfolio (Reference Only)

This directory contains the previous Next.js + Emotion portfolio implementation for reference during the refactor to Astro + Tailwind.

## Structure

- `components/` - React components from the previous implementation
- `pages/` - Next.js pages (index, about, skills)
- `styles/` - Emotion styles and theme configuration
- `utils/` - Utility functions, constants, and types
- `public/` - Static assets (images, icons, PDFs)

## Purpose

This directory is kept for reference only to understand:
- Component structure and functionality
- Page content and routing
- Styling patterns (to be migrated to Tailwind)
- Data structures and constants
- Asset organization

**Note**: This code is not meant to be runnable. It's preserved solely for reference during the migration.
